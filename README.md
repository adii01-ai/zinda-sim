# SIM Keeper — docs for Claude Code

## How to use
1. Create an empty folder for the app, e.g. `SimKeeper/`, and open it in VS Code.
2. Copy every `.md` file from this folder into the project root (CLAUDE.md must be at the root so Claude Code loads it automatically).
3. Start Claude Code in that folder and say:
   > Read CLAUDE.md and all the docs it lists. Then do Milestone 1 from TASKS.md. Stop after each milestone so I can build and check it.
4. After each milestone run `./gradlew assembleDebug`, try it on your phone, then ask for the next milestone.
